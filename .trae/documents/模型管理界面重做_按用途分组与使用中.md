## Proposed Changes

### 1. `app/core/model_manager.py` — 新增四个纯函数（可单测）

- `default_whisper_tier() -> str`：返回 `"small"`，与 `AsrSettings` 默认档位保持单一来源。
- `installed_whisper_tiers(root) -> list[str]`：按 `WHISPER_TIERS` 顺序返回 `installed_state(...).ready` 的档位。
- `installed_llm_specs(root) -> list[ModelSpec]`：遍历 `models/llm/*/*.gguf`，按文件名 `Qwen3.5-{size}-{quant}.gguf` 反解 → `llm_spec(size, quant)`；解析不出的文件跳过并在调用方日志里提一句。
- `installed_llm_file(spec, root) -> Path | None`：返回该档位具体的 gguf 路径（供 Ollama 名字推导）。

### 2. `app/core/semantic.py` — 模型名推导提成公开函数

`ollama_model_name_for(path: Path) -> str`（把 `auto_model_name()` 里那三段推导搬出来），`auto_model_name()` 改为 `path = locate_llm_model(); return ollama_model_name_for(path) if path else None`。**行为不变**，只是让"指定档位"能复用同一套命名规则。

### 3. `app/core/app_config.py` — 记录"使用中"

- 新增 `asr_model_tier: str | None = None`、`llm_model_key: str | None = None`（`None` = 用默认：转写 `default_whisper_tier()`、语义按现有的自动规则）。
- `load()` 校验：tier 必须在 `WHISPER_TIERS` 内、key 必须能被 `spec_by_key()` 解析且 `kind == "llm"`，非法值回落 `None`（与既有的主题/目录校验同一路子）。
- 移除 `last_download_key`（被"使用中"取代；旧配置文件里的该字段会被 `load()` 忽略，无害）。

### 4. `app/gui/workers.py` — 让配置真正生效

- 转写阶段（L227）：`tier = AppConfig.load().asr_model_tier or default_whisper_tier()`，`AsrSettings(model_tier=tier)`。
  - 缓存键自动跟随（`AsrSettings.cache_parts()` 含 `model_tier`，[asr.py:398](file:///c:/Users/cct20/Desktop/drama-splitter/app/core/asr.py#L398)）→ 换档位不会串用旧转写，无需额外处理。

## Assumptions & Decisions

- **「使用中」只对已安装档位可设**；未安装不可设（避免"选了但用不了"的假状态）。下载完成不会自动改配置，只提示可以设。
- 转写的"使用中"**必须**有值（默认 `default_whisper_tier()`＝small）：未安装时界面红字说明后果，而不是静默降级到 tiny。
- 语义模型的"使用中"对 **Ollama** 生效（本机唯一装得上的推理栈）；进程内 llama.cpp 路径不区分档位（同目录、按体积取），在推理栈状态行如实标注，不假装可选。
- 推理栈状态后台探测（最长 3 秒），探测期间显示"探测中…"，失败即"不可用（降级为规则评分）"。
- 保留既有能力：逐文件进度、取消、磁盘预检、删除、目录可改并持久化；`installed_state` 三态语义不变。
- 不新增"远端体积预取/逐档位实测"等能力（体积仍用目录实测 + 清单里的预估）。
- `last_download_key` 移除；旧配置文件里的该键被忽略。
